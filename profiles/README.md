# Keep my data

These files install from Safari. They do **not** erase the iPhone.

The name inside each file is what iOS shows under VPN & Device Management:

| File | On iPhone |
| --- | --- |
| `OpenHat-Level-1-Mullvad.mobileconfig` | OpenHat Security: Level 1 (Mullvad) |
| `OpenHat-Level-1-Quad9.mobileconfig` | OpenHat Security: Level 1 (Quad9) |
| `OpenHat-Level-2.11-*.mobileconfig` | Level 2.11 — one extra (PIN) |
| `OpenHat-Level-2.12-*.mobileconfig` | Level 2.12 — one extra (Safari) |
| `OpenHat-Level-2.21-*.mobileconfig` | Level 2.21 — two extras (PIN + Safari) |
| `OpenHat-Extras-1.1.mobileconfig` | OpenHat Extras 1.1 |
| `OpenHat-Extras-1.2.mobileconfig` | OpenHat Extras 1.2 |

They cannot hide Instagram or Snapchat. That needs Level 4 — see `../wipe-required/`.
