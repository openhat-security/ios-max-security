Removal

Remove a profile

A configuration profile is not permanent. You can take it off the same screen Apple uses to install it.

Configuration profiles (Levels 1, 2, extras)

  1. Open Settings → General → VPN & Device Management.
  2. Tap the OpenHat profile you installed.
  3. Tap Remove Profile (or Remove).
  4. Enter your passcode if asked.

Repeat for each profile if you installed more than one (for example Level 2 plus an extras file).

What comes back

  • Encrypted DNS from the profile stops. The phone uses the carrier or Wi-Fi DNS again.
  • Restrictions in that file stop applying.
  • A passcode you already set stays until you change it in Settings.
  • Safari content-filter blocks from an extras profile go away with that profile.

Lockdown Mode

Lockdown Mode is not a profile. Turn it off in Settings → Privacy & Security → Lockdown Mode.

MDM enrollment (Level 4.1)

On the same VPN & Device Management screen, tap the enrollment profile and remove it. Settings that came from your server stop after the profile is gone.

Supervised devices (Level 4.2)

Removing a profile does not unsupervise the phone. To leave Supervision, erase the device or restore a backup from before you used Apple Configurator to Prepare it. There is no unsupervise toggle.
